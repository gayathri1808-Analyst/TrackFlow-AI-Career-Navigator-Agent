# 🚀 TrackFlow AI – Career Navigator Agent

An AI-powered multi-agent career guidance platform built using Google's Agent Development Kit (ADK), Gemini API, Python, and SQLite.

---

## 📖 Overview

TrackFlow AI is a modular AI-powered career guidance platform that helps students prepare for placements and career growth using multiple intelligent agents.

Each agent is responsible for a specific career guidance task, making the platform scalable and easy to extend.

---

## ✨ Features

- 👨‍🏫 Career Mentor Agent
- 📄 Resume Review Agent
- 📊 Skill Gap Analyzer
- 🎤 Interview Coach Agent
- 🎯 Personalized Career Guidance
- 📈 ATS Resume Analysis
- 🛣️ Career Roadmap Generation
- 💾 SQLite Database Integration
- 🤖 Multi-Agent Architecture

---
